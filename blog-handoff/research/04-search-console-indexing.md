# 지원포유 색인 점검 자료 (서치콘솔·블로거)

- 점검일: 2026-10-22 (서치콘솔 수치는 운영자 제공 10/21 기준)
- 관련 글감: T17, T18
- 이 자료는 운영자 본인 블로그의 1차 데이터라 그대로 글감이 된다.

| --- | --- |

## 기술 점검 결과 (정상)
- 서버 응답: 데스크톱·모바일 구글봇 모두 200. 모바일은 302로 `?m=1`(블로거 기본 동작), `?m=1` 페이지의 canonical은 원래 주소.
- robots.txt: `User-agent: *` / `Allow: /`, 사이트맵 2개(`sitemap.xml`, `sitemap-pages.xml`).
- 글 페이지 `x-robots-tag: all`, noindex 없음. 라벨·검색·날짜 목록 페이지는 `noindex, follow`(의도된 정상 설정).
- 대표 주소: `jiwon4u.kr` → `https://www.jiwon4u.kr/` 301.
- 테마(JetTheme) 스크립트는 `?m=1`을 `history.replaceState`로 주소창에서만 지움(페이지 재요청 없음). JS 이동·meta refresh 없음.
- 구글 애널리틱스 4 태그 있음. 도메인 TXT 레코드 없음(가비아 DNS) → 서치콘솔 도메인 속성은 CNAME 등 다른 방식으로 인증됐을 가능성, 또는 레코드 삭제 시 소유권이 풀릴 위험.

## 리디렉션 체인 테스트 (모바일 구글봇, 사이트맵 37개 주소 전부)

| 시작 주소 | 결과 |
| --- | --- |
| `https://www.jiwon4u.kr/글` | 37개 모두 이동 1회(→ `?m=1`) 후 200 |
| `http://jiwon4u.kr/글` (가장 먼 경로) | 37개 모두 이동 3회 후 200 |
| 데스크톱 구글봇 | 이동 없이 200 |

루프 없음. 구글봇은 최대 10회까지 따라감 → 현재 상태로는 "리디렉션 오류" 재현 안 됨.

## "리디렉션 오류"의 정의 (구글 문서·가이드 기준)
이동을 따라가다 실패한 경우: ① 체인이 너무 김 ② 루프 ③ 주소가 최대 길이 초과 ④ 체인 중간에 빈/잘못된 주소.
"리디렉션이 포함된 페이지"는 오류가 아니라 정상 제외(주로 http, www 없는 주소).

## 가능성 정리 (확정 아님)
1. 다른 상태("리디렉션이 포함된 페이지")와의 혼동
2. 과거 특정 시점 문제의 기록이 남음(개인 도메인 연결 직후 HTTPS 인증서 발급 전, 10/19 테마 작업 중 등)
3. 구글 쪽에서만 보이는 문제

## 서치콘솔에서 할 일 (글의 "해결 순서"로 사용)
1. 정확한 문구 확인(리디렉션 오류 vs 리디렉션이 포함된 페이지)
2. 해당 22개 목록의 주소 형태와 "최근 크롤링" 날짜 확인
3. 한 편을 URL 검사 → "실제 URL 테스트". 통과하면 지난 기록 → 오류 화면에서 "수정사항 확인" 클릭
4. 실제 테스트도 실패하면 주소와 상세 화면을 보관하고 재추적

## 서치콘솔 상태 메시지 뜻 (T18 뼈대)
| 메시지 | 뜻 | 할 일 |
| --- | --- | --- |
| 색인됨 | 검색 결과에 나올 수 있음 | 없음 |

| noindex 태그에 의해 제외됨 | 의도적으로 제외(라벨·검색 페이지) | 의도인지 확인 |
