# 클로드 코드에 붙여넣는 작업 지시문

VS Code에서 `blog-handoff` 폴더를 연 뒤, 클로드 코드 대화창에 아래 문장을 붙여넣으세요.
`CLAUDE.md`의 규칙은 클로드 코드가 자동으로 읽습니다.

## 1. 원고 한 편 쓰기

```text
topics.json에서 T42 글감으로 원고를 써 줘.
research 폴더의 관련 자료만 근거로 쓰고, templates/post-template.md 형식을 따라.
자료에 없는 사실은 [✅ 확인 필요]로 표시하고, 직접 경험이 필요한 곳은 자리 표시로 남겨.
drafts/에 저장하고 topics.json의 status와 draft 경로를 고쳐 줘.
```

## 2. 다음에 쓸 글 고르기

```text
topics.json에서 status가 ready인 글감 중에 지금 쓰면 좋은 순서로 5개 골라 줘.
data/jiwon4u-posts.csv와 검색어가 겹치지 않는지도 같이 확인해.
```

## 3. 발행 전 확인 목록 뽑기

```text
drafts/2026-10-free-ai-video-limits.md에서 발행 전에 공식 페이지로 다시 확인해야 할 사실을 표로 뽑아 줘.
항목, 원고 속 문장, 확인할 공식 주소 순서로.
```

## 4. 실습이 필요한 글 준비

```text
T36(하이퍼프레임으로 카드뉴스를 숏츠로) 글을 쓰기 위해 내가 직접 해야 할 실습 순서와,
결과를 기록할 양식(캡처 목록, 걸린 시간, 막힌 곳)을 만들어 줘. research/02-ai-video-tools.md를 참고해.
```

## 5. 카드뉴스만 뽑기

```text
drafts/2026-10-photoshop-free-fact-check.md의 카드뉴스 원고를 1080x1350 카드 6장 HTML로 만들어 줘.
```

## 6. 기존 글 보강 제안

```text
data/jiwon4u-posts.csv의 기존 글 중 research 자료로 보강할 수 있는 글을 찾아서,
글마다 추가하면 좋은 문단과 근거 자료를 알려 줘. 한꺼번에 수정하지 말고 제안만.
```
