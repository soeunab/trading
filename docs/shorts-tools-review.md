- 대상: 유튜브에서 "영상 만드는 스킬", "포토샵 무료", "무료 AI 영상", "클로드 스킬 추천" 같은 문구로 검색한 영상 219편 중 주제에 맞는 60편
- 방법:
  1. 검색 결과에서 제목·채널·조회수를 모았다.
  2. 60편은 설명란까지 읽고, 소개하는 도구와 링크를 뽑았다.
  3. 도구마다 공식 문서, 요금 페이지, GitHub 저장소로 사실을 확인했다. 아무것도 설치하거나 실행하지 않았다.
- 한계: 유튜브 검색으로는 숏츠만 정확히 거를 수 없어서, 같은 문구를 쓰는 일반 영상(롱폼)도 섞여 있다. 영상 내용(음성)은 보지 못했고 제목과 설명란 기준이다.

## 3. 지원포유가 쓸 만한 것

기준: 맥 사용, 클로드(웹·클로드 코드) 사용, 블로그 + 인스타·스레드 카드뉴스 운영, 무료 우선.

### ★ 바로 써 볼 만한 것

| 순위 | 도구 | 쓰는 곳 | 비용·조건 | 비고 |
| --- | --- | --- | --- | --- |
| 1 | **하이퍼프레임(HyperFrames)** | 카드뉴스를 **릴스·숏츠용 모션 영상**으로 바꾸기 | 무료 오픈소스(Apache 2.0), 상업 이용 가능. 클로드 코드 플러그인, 맥 앱 있음. Node.js 22+, FFmpeg 필요 | HTML로 만드는 방식이라 카드뉴스 자동화와 잘 맞는다. 게으른 빌더식 릴스 유입 전략의 출발점 |
| 2 | **리모션(Remotion) 공식 스킬** | 하이퍼프레임과 같은 용도의 대안 | 개인·직원 3명 이하 회사는 무료. 그보다 크면 유료 | 반드시 `remotion-dev` 공식 저장소에서 받기(비슷한 이름의 복제본이 많다). 1번과 둘 중 하나만 고르면 된다 |
| 3 | **포토샵 모바일 앱 (무료 기본판)** | 썸네일·카드뉴스 사진 손보기 | 무료(고급 기능은 월 $7.99) | 아이폰·아이패드에서 레이어, 마스크, 선택 |
| 4 | **포토스케이프 X** | 맥에서 사진 자르기·보정·글씨 넣기 | 맥 앱스토어 무료(Pro는 일회성 $39.99) | 한국 회사가 만든 프로그램 |
| 5 | **Clipdrop** | 배경 제거(누끼), 업스케일, 지우기 | 웹에서 각각 하루 20회 무료 | 카드뉴스 인물·제품 누끼용 |
| 6 | **구글 플로우 / 구글 Vids** | 가끔 실사 느낌의 짧은 클립이 필요할 때 | 플로우 하루 50크레딧, Vids 월 10편 무료 | "무제한" 아님. 아껴 쓰기 |
| 7 | **Vrew** | 영상 자막 자동 생성 | 무료 월 200크레딧(자막 약 200분) | 맥 앱 있음 |
| 8 | **prompt-master 스킬** | 카드뉴스 이미지·영상 프롬프트 다듬기 | 무료(MIT), 스크립트 없이 문서만 있음 | 클로드 웹에 ZIP으로 올려서도 쓸 수 있다 |
| 9 | **hwpxskill** | 클로드로 한글(HWPX) 파일 만들기 | 무료. 단, 라이선스 표기가 없어 고친 버전을 배포하지는 말 것 | 블로그의 "클로드 한글 파일" 글과 연결되는 좋은 후속 소재 |
