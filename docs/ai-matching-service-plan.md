# AI 대화 기반 성향 매칭·모임 서비스 기획안

- 가칭: **튠(Tune)**. "성향의 주파수를 맞춘다"는 뜻이다.
- 작성일: 2026-10-19
- 참고: [제타 성공 요인 벤치마킹](./zeta-ai-success-benchmark.md)

---

## 1. 한 줄 정의

> **AI와 편하게 대화하다 보면, AI가 나를 이해하고 나와 잘 맞는 사람과 모임을 먼저 제안해 주는 서비스.**

출발점은 AI 대화이고 목적지는 사람이다.
기존 데이팅앱은 사진과 짧은 소개를 보고 넘기는(스와이프) 방식이라서 "이 사람이 나와 맞는지"를 알기 어렵다.
튠은 **대화 속에서 쌓인 성향 데이터**로 연결한다. 데이터는 성격, 음악 취향, 취미, 가치관, 생활 지역이다.

## 2. 왜 이 구조인가

| 문제 | 기존 서비스 | 튠의 해법 |
| --- | --- | --- |
| 프로필 작성이 귀찮고 다들 비슷하게 쓴다 | 설문, 자기소개 | AI와 대화만 하면 성향 프로필이 **자동으로** 만들어진다 |
| 외모 위주 매칭 | 사진 스와이프 | 성향·취향 궁합이 먼저, 사진은 나중에 |
| 첫 만남이 부담스럽다 | 바로 1:1 | **모임(1:N)**부터 시작할 수 있다 |
| 앱을 켤 이유가 매칭 말고는 없다 | 매칭이 끝나면 이탈 | AI 대화 자체가 재미있어서 **매일 켠다** (제타식 체류) |
| 추천 이유를 모른다 | 블랙박스 | AI가 "왜 이 사람인지"를 설명한다 |

제타에서 배운 핵심: **사람들이 매일 시간을 쓰는 이유(AI 대화의 재미)**와 **돈을 내는 이유(사람과의 연결)**를 분리해서 설계한다.

## 3. 타깃과 사용 장면

| 페르소나 | 상황 | 튠에서 하는 일 |
| --- | --- | --- |
| 지민 (27, 직장인, 이직 후 서울 정착) | 동네에 아는 사람이 없다 | AI와 퇴근 후 수다 → "성수동에서 인디밴드 좋아하는 사람 4명이 토요일 LP바 모임을 해요" 제안 |
| 도현 (31, 연애 공백 3년) | 소개팅앱은 피곤하다 | AI와 연애관 대화 → "대화 스타일과 주말 보내는 방식이 잘 맞는 분이 있어요" 1:1 제안 |
| 수아 (24, 대학원생) | 클라이밍을 같이 할 사람이 필요하다 | 취미 이야기 중 → "근처 암장에서 주 2회 오는 비슷한 실력의 사람들" 제안 |

- **1차 타깃**: 20~35세, 수도권, 이사·이직·졸업으로 생활권이 바뀐 사람
- **서비스 연령**: 연애 매칭은 **만 19세 이상만** 허용한다(7장 참고).

## 4. 핵심 사용자 흐름

```
① AI 대화           매일 수다, 고민 상담, 음악·취미 이야기
      ↓            (AI가 대화에서 성향 신호를 추출)
② 나의 성향 카드     성격·음악·취미·가치관·활동 지역을 자동 정리
      ↓            사용자가 직접 확인하고 고치고, 공개 범위를 정한다
③ AI의 제안          대화 흐름 속에서 자연스럽게
      ↓            "그 밴드 좋아하는 사람이 근처에 3명 있는데, 볼래요?"
④ 미리보기 (무료)    궁합 점수, 공통점 3가지, 흐린 프로필
      ↓
⑤ 열람·연결 (유료)   전체 프로필 보기, 관심 보내기, 모임 참가 신청
      ↓
⑥ 서로 수락          양쪽이 모두 수락해야 연결된다 (더블 옵트인)
      ↓
⑦ AI 아이스브레이커  첫 대화 주제 추천, 공통 관심사로 대화 시작 도움
      ↓
⑧ 만남·모임 후기     후기가 매칭 품질과 신뢰도 점수로 돌아간다
```

### AI가 제안하는 원칙

1. **대화 흐름을 끊지 않는다.** 사용자가 관련 주제(외로움, 취미, 음악, 주말 계획)를 꺼냈을 때만 제안한다.
2. **빈도를 제한한다.** 하루 최대 1~2회. 영업처럼 느껴지면 AI 대화의 신뢰가 깨진다.
3. **이유를 설명한다.** "둘 다 새벽에 Lo-fi를 듣고, 주말엔 집보다 밖을 좋아하고, 같은 구에 살아요."
4. **거절을 존중한다.** "지금은 그냥 얘기만 하고 싶어"라고 하면 일정 기간 제안하지 않는다.
5. **고민 상담 중에는 제안하지 않는다.** 힘든 이야기를 하는 사람에게 결제 유도를 하면 안 된다. 이건 윤리 원칙이자 브랜드 원칙이다.

## 5. 주요 기능

### 5.1 AI 동반자

- 성격이 다른 AI 캐릭터 몇 명 중에서 고른다(예: 공감형 친구, 음악 덕후, 수다쟁이 동네 언니).
- 대화를 기억해서 "지난주에 말한 면접 어떻게 됐어?" 같은 **이어지는 대화**를 한다.
- "상담"은 친구 같은 대화로 정의한다. **심리치료나 의료 서비스로 홍보하지 않는다.**

### 5.2 성향 프로필 (대화에서 자동 추출)

| 축 | 예시 신호 | 수집 방식 |
| --- | --- | --- |
| 성격 | 외향·내향, 계획형·즉흥형, 대화 스타일 | 대화 분석 + 가벼운 성격 퀴즈 |
| 음악 | 장르, 아티스트, 공연 경험, 듣는 시간대 | 대화 + (선택) 음악 서비스 재생기록 연동 |
| 취미 | 운동, 독서, 게임, 요리, 여행 | 대화 + 태그 선택 |
| 가치관 | 연애관, 일과 삶의 균형, 생활 리듬 | 대화 (연애 매칭을 켠 사람만) |
| 지역 | 활동하는 동·구, 이동 가능 범위 | 사용자가 직접 설정, 동 단위까지만 |
| 목적 | 친구, 모임, 연애 | 사용자가 직접 선택. 섞어서 고를 수 있다 |

- **사용자가 최종 결정권을 가진다.** AI가 추출한 내용은 "이렇게 이해했는데 맞아?" 형태로 보여 주고, 사용자가 승인한 항목만 매칭에 쓴다.
- 고민 상담 내용 원문은 **매칭 상대에게 절대 보여 주지 않는다.** 매칭에는 요약된 성향 태그만 쓴다.
- 건강, 종교, 정치, 성적 지향 같은 **민감정보는 기본적으로 매칭에 쓰지 않는다.** 사용자가 원하면 따로 동의를 받는다.

### 5.3 매칭 엔진

```
후보 생성                       재정렬                          노출
 성향 임베딩 유사도      →      상호 관심 가능성(양방향 예측)  →  하루 제안 수 제한
 + 지역·목적·연령 필터           활동성(최근 접속)                 "왜 추천했는지" 설명
 + 차단·이미 본 사람 제외        신뢰도(인증·후기·신고 이력)
                                 공정한 노출(인기인 쏠림 방지)
```

- **유사성과 보완성을 함께 본다.** 음악·취미는 비슷할수록 좋고, 대화 스타일은 적당히 다를 때 잘 맞는 경우가 많다. 후기 데이터로 계속 보정한다.
- **양방향 매칭**: 내가 좋아할 사람이 아니라, **서로 수락할 확률이 높은 사람**을 추천한다. 그래야 연결 성공률이 올라간다.

### 5.4 모임

| 유형 | 설명 | 예시 |
| --- | --- | --- |
| AI 큐레이션 모임 | 서비스가 성향이 맞는 4~6명을 묶어 장소와 시간을 정해 준다 (Timeleft 방식) | "목요일 저녁 망원동, 시티팝 좋아하는 5명 LP바 모임" |
| 호스트 모임 | 사용자가 모임을 열면 AI가 맞는 사람을 초대한다 | 러닝 크루, 북클럽, 보드게임 |
| 공연·이벤트 동행 | 같은 공연 티켓을 산 사람 중 성향이 맞는 사람끼리 연결 | 페스티벌 동행, 내한 공연 뒷풀이 |

모임은 1:1보다 부담이 적어서 **첫 경험으로 좋고**, 한 번에 여러 명이 결제하므로 **매출 단위도 크다**.

### 5.5 안전

- 휴대폰 본인인증 필수. 셀카 얼굴 인증 배지는 선택.
- 첫 만남은 공공장소 권장, 위치 공유 기능, 만남 체크인과 귀가 확인.
- 신고·차단, 대화 저장, 업자·스캠 탐지(외부 링크, 금전 요구, 투자 권유 패턴).
- 위기 신호(자해·자살 언급)가 있으면 대화를 멈추고 **자살예방상담전화 109** 등 전문 기관을 안내한다. 이때는 어떤 제안도 하지 않는다.

## 6. 수익 구조

### 6.1 원칙

- **AI 대화는 무료**로 한다. 매일 켜게 만드는 장치다.
- **제안을 보는 것(미리보기)도 무료**로 한다. 가치를 먼저 보여 줘야 결제한다.
- **연결하는 순간에 과금**한다. 열람, 관심 보내기, 모임 참가.
- 신뢰를 위해 **"연결 안 되면 환불"** 옵션을 둔다(상대가 7일 안에 수락하지 않으면 재화 반환).

### 6.2 수익원 (가격은 검증 전 가설)

| # | 수익원 | 내용 | 가격 가설 |
| --- | --- | --- | --- |
| 1 | **제안 열람권** | AI 제안의 전체 프로필과 궁합 리포트 열기 | 건당 2,900원 / 5회 9,900원 |
| 2 | **관심 보내기 재화 "튠"** | 관심 보내기, 먼저 메시지 보내기, 슈퍼관심 | 10튠 4,900원 ~ 100튠 39,000원 |
| 3 | **구독 "튠 플러스"** | 하루 제안 수 증가, 열람 무제한, 지역 범위 확장, 누가 나를 봤는지 확인 | 월 14,900원 |
| 4 | **구독 "튠 프리미엄"** | 플러스 + 상세 궁합 리포트, 우선 노출, AI 연애 코칭 | 월 29,900원 |
| 5 | **AI 큐레이션 모임 티켓** | 서비스가 짠 4~6인 모임 참가권 (음식값 별도) | 회당 9,900~19,900원 |
| 6 | **호스트 모임 수수료** | 사용자가 연 유료 모임 참가비에서 수수료 | 참가비의 10~15% |
| 7 | **성향 리포트 단건** | "나의 연애 성향", "나의 음악 DNA" 같은 공유용 리포트 | 3,900원 (공유 시 바이럴) |
| 8 | **제휴 수수료** | 공연 티켓, 모임 장소(카페·펍·공방) 예약 수수료, 장소 측 프로모션 비용 | 거래액의 5~10% |
| 9 | **광고** | 무료 이용자 대상, 대화 흐름을 해치지 않는 위치에만 | CPM |
| 10 | **B2B** | 기업 사내 동호회·신입 온보딩 매칭, 지자체 청년 교류 프로그램 운영 | 계약 단위 |

### 6.3 단계별 수익 무게중심

```
초기 (0~6개월)    모임 티켓 + 열람권     ← 이용자가 적어도 매출이 나고 효과를 체감한다
성장 (6~18개월)   구독 + 재화            ← 반복 매출
확장 (18개월~)    제휴 + B2B + 광고      ← 이용자 규모와 데이터를 활용
```

### 6.4 단위 경제성 (예시 계산, 검증 필요)

| 항목 | 가정 |
| --- | --- |
| 월간 이용자(MAU) | 100,000명 |
| 유료 전환율 | 6% → 6,000명 |
| 유료 이용자 1인당 월 매출(ARPPU) | 18,000원 |
| 월 매출 | 약 1억 800만 원 (+ 모임·제휴·광고 별도) |
| AI 대화 원가 | 1인당 월 300~800원 목표 (소형 모델 + 대화 요약 기억 + 캐싱) |

제타처럼 **대화 1회당 원가**를 낮추는 것이 무료 대화를 유지하는 열쇠다.
일상 대화는 저렴한 모델로, 성향 추출과 궁합 리포트처럼 중요한 작업만 상위 모델로 나눠 처리한다.

## 7. 법·규제 체크리스트 (출시 전 전문가 확인 필수)

| 항목 | 내용 | 대응 |
| --- | --- | --- |
| 청소년 보호 | 불특정 다수 간 만남·대화 서비스는 청소년유해매체물 규제 대상이 될 수 있다. 랜덤채팅앱은 2020년 고시로 규제 대상이 됐다. | 연애 매칭과 1:1 연결은 **만 19세 이상 본인인증 필수**로 운영한다 |
| 위치정보법 | 이용자 위치로 사람을 추천하면 위치기반서비스사업자 신고가 필요할 수 있다 | 동 단위로 직접 입력받는 방식으로 시작하고, GPS를 쓰게 되면 신고 후 도입 |
| 개인정보보호법 | 상담 대화에는 건강, 신념 같은 **민감정보**가 섞일 수 있다 | 민감정보 별도 동의, 매칭에서 기본 제외, 원문은 비공개, 보관 기간 설정 |
| AI기본법 (2026.1 시행) | AI 기반 서비스임을 미리 알려야 하고, 생성물 표시 의무가 있다 | 온보딩과 대화창에 "AI입니다" 고지, AI 생성 이미지 표시 |
| 결혼중개업법 | "결혼 중개"를 표방하면 결혼중개업 신고 대상이 될 수 있다 | 친구·모임·연애 매칭으로 포지셔닝하고, "결혼 보장" 같은 표현은 쓰지 않는다 |
| 전자상거래법 | 구독 자동결제, 재화 환불 | 결제 전 고지, 해지 쉽게, 미사용 재화 환불 정책 |
| 의료·심리 표방 | "심리상담", "치료"라는 표현은 오해 소지가 있다 | "대화 친구"로 표현하고, 위기 시 전문기관 안내 |

> 이 표는 기획 단계의 점검 목록이다. 실제 적용 여부는 변호사 검토가 필요하다.

## 8. 제타에서 가져올 것

| 제타의 성공 요인 | 튠에 적용 |
| --- | --- |
| 재미가 최우선 | AI 대화 자체가 재미있어야 한다. 매칭은 그 위에 얹는다 |
| 자체 소형 모델로 원가 절감 | 일상 대화는 저렴한 모델, 중요한 판단만 상위 모델 |
| 광고 + 유료 티어 | 무료 대화 + 연결 시점 과금 + 구독 |
| UGC 플라이휠 | 사용자가 여는 호스트 모임 = 콘텐츠 공급 |
| 대화 밖 몰입 장치 | 성향 카드, 음악 DNA 리포트, 궁합 리포트 (공유용) |
| 익명 진입 | AI 대화는 가입 없이 시작하고, 매칭할 때 본인인증 |
| 서버 주도 홈 화면 | 이번 주 모임, 동네 인기 취미를 운영자가 바로 바꿀 수 있게 |
| **반면교사: 청소년 안전 문제** | **처음부터 성인 인증, 유해 대화 탐지, 안전 기능을 갖춘다** |

## 10. 실행 로드맵

| 단계 | 기간 | 범위 | 성공 기준 |
| --- | --- | --- | --- |
| 0. 검증 | 1개월 | 랜딩 페이지 + 카카오톡 오픈채팅으로 수동 매칭 모임 10회 | 모임 만족도 4/5 이상, 재참가 의향 50% 이상 |
| 1. MVP | 3개월 | AI 대화(캐릭터 1~2개), 성향 카드, AI 큐레이션 모임(한 지역, 음악 주제), 모임 티켓 결제 | 대화 사용자 중 모임 신청 전환 5%, 재참가율 30% |
| 2. 1:1 연결 | +3개월 | 1:1 제안, 열람권·재화, 더블 옵트인, 안전 기능 | 제안 수락률 15%, 결제 전환 4% |
| 3. 성장 | +6개월 | 구독, 호스트 모임, 지역·주제 확장, 공연 제휴 | MAU 10만, 유료 전환 6% |
| 4. 확장 | 이후 | B2B, 광고, 다른 도시 | 매출 다각화 |

### 핵심 지표

- **AI 대화**: 일간 활성 사용자, 1인당 하루 대화 시간, D7 리텐션
- **매칭**: 제안 수락률, 서로 수락률, 첫 메시지 응답률, 실제 만남 전환율
- **모임**: 신청 → 참석률(노쇼율), 만족도, 재참가율
- **수익**: 유료 전환율, ARPPU, 대화 1회당 원가
- **안전**: 신고율, 스캠 차단 건수, 신고 처리 시간

## 11. 기술 구성 (초안)

```
앱 (웹/모바일)
 ├─ AI 대화 서비스   LLM (일상 대화: 소형 모델 / 성향 추출·리포트: 상위 모델)
 │                   대화 요약 기억, 안전 필터, 위기 신호 감지
 ├─ 성향 프로필      대화 → 구조화된 태그 추출 → 사용자 승인 → 임베딩 저장
 ├─ 매칭 서비스      벡터 검색(후보) → 재정렬 모델 → 제안 큐 (빈도 제한)
 ├─ 모임 서비스      일정, 장소, 정원, 결제, 체크인, 후기
 ├─ 결제            구독, 재화, 티켓, 환불
 └─ 안전·운영       본인인증, 신고·차단, 스캠 탐지, 관리자 도구, 실험(A/B)
```

## 12. 다음에 정할 것

1. **첫 타깃 주제와 지역**: 음악 / 운동 / 독서 중 무엇으로, 어느 동네에서 시작할지
2. **연애 매칭을 처음부터 넣을지**, 아니면 친구·모임으로 시작해서 나중에 열지
