# 게으른 빌더(lazyowen.com) 구조·수익구조 분석

- 대상: https://lazyowen.com/
- 분석일: 2026-10-29
- 방법: [REA (Reverse Engineer Anything)](https://github.com/morluto/rea)의 웹 분석 순서(페이지 캡처 → 번들 분석 → 스크립트 추출)를 따랐다.
  이 환경에서는 `rea-agents` npm 패키지 실행이 권한 정책으로 막혀 있어서, 같은 단계를 curl로 직접 수행했다.
- 범위: 공개 페이지 10여 개, 사이트맵, robots.txt, 공개 JS 번들 13개(약 712KB)만 읽었다.
  이메일 등록, 문의 폼 전송, 로그인, 결제는 하지 않았다.
- 참고: 사이트의 robots.txt는 AI 학습용 크롤러(ClaudeBot, GPTBot 등)를 막는다. 이 분석은 사용자 요청으로 공개 페이지를 한 번 읽은 것이고 학습용 수집이 아니다.
- 수치 대부분은 **사이트가 스스로 공개한 미디어킷 수치**다. 외부에서 검증하지 않았다.

## 1. 한 줄 요약

10년 차 엔지니어가 **인스타그램 릴스로 모은 관심**을 **무료 가이드 사이트 → 이메일 리스트**로 옮기고,
그 리스트와 채널 지표로 **브랜드 협찬**과 **유료 강의 구독(월 49,000원)**을 파는 1인 크리에이터 비즈니스다.
슬로건은 "수익 인증 대신 빌드 인증".

## 3. 사이트 구조

### 3.1 페이지 구성

| 경로 | 역할 |

| `/contact` | 협업·취재·막힘 문의 안내 |
| `/refund` | "게으른 빌더 클래스"(온라인 강의 구독) 환불 정책 (2026-10-23 시행) |

### 3.3 이메일 게이트 방식

- 가이드 앞부분(요약, Quick Start, STEP 1)은 공개하고, 나머지 섹션은 **"이메일 하나면 전부 무료"** 카드로 가린다.
- 이메일을 한 번 넣으면 쿠키와 브라우저 저장소에 "열림" 표시가 남아 **모든 가이드가 함께 열린다**.
- 가려진 본문도 **HTML에는 그대로 들어 있고 화면에서만 가리는 방식**이다.
  - 장점: 검색엔진이 전체 본문을 읽을 수 있어 검색 유입에 유리하다.
  - 단점: 마음먹으면 이메일 없이도 볼 수 있다. 다만 "자료를 받으려는 사람"이 이메일을 남기게 하는 효과는 충분히 낸다.
- 이메일 동의 문구에 "가이드 소식·주간 AI 소식, **사업 소식(광고)**"을 함께 받는다고 명시한다. 광고성 정보 수신 동의를 같이 받는 구조다.

## 4. 유입·전환 퍼널

```
① 인스타 릴스 / 카드뉴스 (주 3회 이상, 비팔로워 도달 94.7%)
      ↓  "자료 주세요" 같은 키워드 댓글 (댓글률 5.2%)
② 댓글 키워드 자동 DM으로 가이드 링크 발송
      ↓
③ lazyowen.com 가이드 (앞부분 공개, 복붙 프롬프트)
      ↓  나머지를 보려면 이메일 등록
④ 이메일 리스트 23,475명
      ├─ 주간 AI 소식 + 사업 소식(광고)
      ├─ 30일 AI 챌린지 사전등록 → 얼리버드 할인 안내
      └─ 유료 강의 구독 "게으른 빌더 클래스" (준비 중)
⑤ 채널 지표 + 리스트 + 사이트 트래픽 → 미디어킷으로 브랜드 협찬 판매
```

핵심은 **댓글이 곧 전환 신호**라는 점이다. 댓글이 많을수록 알고리즘 노출이 늘고, 동시에 자동 DM으로 사이트 방문과 이메일 수집이 일어난다.

### 5.2 협찬 판매 방식

- **진행 절차**: 문의 → 계약 후 1영업일 안에 스크립트 초안 → 승인 시 **50% 선지급** → 5영업일 안에 검토 영상(수정 2회) → 게시 → 게시 후 5영업일 안에 잔금 50%
- **단가 산정식을 공개**한다: `CPM = 집행가 ÷ (예상 조회수 ÷ 1,000)`, `CPE = 집행가 ÷ 예상 참여수`. 예상 조회는 보수적으로 7.6만 회(보장 아님).
- 금액은 공개하지 않고 문의 시 견적을 준다(부가세 포함).
- **세일즈 포인트**: "보고 넘기는 게 아니라 따라 하는 오디언스". 노출 수가 아니라 **행동 전환율**(댓글 → DM → 사이트 → 이메일)을 판다.
  잘 맞는 광고주로 AI 도구, 노코드, 생산성 앱, 온라인 교육을 꼽는다.
- **신뢰 장치**: "먼저 써 보고 안 맞으면 거절", "설치부터 실제로 굴러가는 것까지 보여 줌", "영상이 끝나도 자료로 남김(노출이 하루로 끝나지 않음)".

### 5.3 매출 규모 (가정에 따른 예시, 실제 수치 아님)

사이트는 매출을 공개하지 않는다("수익 인증 안 함"). 아래는 공개 지표에 가정을 얹은 계산 예시다.

| 항목 | 가정 | 계산 |
| --- | --- | --- |
| 유료 강의 구독 | 이메일 23,475명 중 1~3%가 월 49,000원 구독 | 약 235~704명 → **월 1,150만~3,450만 원** |
| 브랜드 협찬 | 월 2~4건 × 건당 금액은 위 CPM 공식에 예상 조회 7.6만을 넣어 산정 | 업계 단가를 모르므로 금액은 계산하지 않음 |

유료 강의가 실제로 출시되면 **수익의 중심이 협찬에서 구독으로 옮겨 갈 가능성**이 크다. 협찬은 알고리즘과 광고주 예산에 흔들리지만, 이메일 리스트 기반 구독은 반복 매출이기 때문이다.

## 6. 성공 요인

1. **댓글 → 자동 DM → 가이드**: 알고리즘이 좋아하는 행동(댓글)과 전환 행동(자료 받기)을 하나로 묶었다.
2. **콘텐츠의 수명 연장**: 릴스는 며칠이면 끝나지만 가이드는 검색과 재방문으로 계속 읽힌다(발행 3일 이후 방문 87%).
3. **이메일로 플랫폼 의존을 줄임**: 인스타 팔로워는 플랫폼 소유지만, 이메일 23,475명은 운영자 자산이다.
4. **복붙 가능한 실전 자료**: 모든 가이드가 "역할·맥락·입력·작업·제약·출력·검증" 형식의 프롬프트와 단계별 소요 시간을 준다.
5. **댓글 요청을 다음 콘텐츠 주제로**: "막힌 곳을 보내 주면 그게 다음 자료 주제가 된다." 수요 확인과 제작이 하나의 고리다.
6. **투명한 미디어킷**: 지표, 단가 산정식, 진행 절차, 정산 조건까지 공개해 광고주가 결정하기 쉽다.
7. **브랜딩**: "게으른 빌더", "수익 인증 대신 빌드 인증". 돈 자랑 계정들과 반대로 포지셔닝해 신뢰를 얻는다.
8. **법적 표시를 갖춤**: 사업자 정보, 개인정보 처리방침, 광고성 정보 수신 동의, 일할 계산 환불 정책을 미리 공개했다.

## 7. 리스크와 개선 여지

| 항목 | 내용 |
| --- | --- |
| 광고 표시 | 브랜드 파트너(Higgsfield)의 추적 링크와 상단 배너가 있는 가이드에서 **"광고", "협찬", "제휴 링크" 같은 표시를 찾지 못했다**. 공정위 추천·보증 심사지침은 경제적 이해관계가 있으면 표시하도록 요구한다. 이 가이드가 유료 협찬인지는 확인할 수 없지만, 표시를 해 두는 편이 안전하다 |
| 통신판매업 신고 | "신고 진행 중". 유료 강의를 판매하기 전에 신고를 마쳐야 한다 |
| 이메일 게이트 | 본문이 HTML에 그대로 있어 이메일 없이도 볼 수 있다. 검색 유입을 생각한 의도적 선택일 수 있다 |
| 플랫폼 의존 | 유입 대부분이 인스타그램이다. 알고리즘이 바뀌면 흔들린다. 이메일 리스트와 검색 유입이 그 완충 역할을 한다 |
| 과장 표현 | "하루 8시간을 10분으로", "300만원 상당의 문서" 같은 문구는 유료 상품 판매가 시작되면 표시광고법상 근거를 요구받을 수 있다 |
| 1인 운영 | 콘텐츠 제작, 협찬, 강의, 문의 응대를 혼자 감당한다. 그래서 운영 자체를 AI 자동화로 돌리는 것이 콘텐츠 주제이기도 하다 |
