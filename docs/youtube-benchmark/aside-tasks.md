# Aside 작업 지시서: 유튜브 채널 벤치마킹 자료 보강

클라우드 분석 환경에서는 아래 자료를 얻을 수 없었습니다. 대표님 컴퓨터의 Aside 브라우저에서 이 지시문을 그대로 붙여넣어 실행하면 빈칸을 채울 수 있습니다.

- Playboard 채널 순위: 로그인(유료 플랜일 수 있음)이 필요함
- Social Blade: 봇 차단(Cloudflare)으로 접속 불가
- 유튜브 채널 '정보' 창(가입일, 총조회수, 국가): 자바스크립트로만 열림
- 영상 태그 전체: 일부 영상은 로그인 확인 화면 때문에 수집이 불완전

결과는 CSV로 저장해서 이 저장소의 `docs/youtube-benchmark/aside-results/` 폴더에 넣거나, 클로드 대화창에 붙여넣어 주세요.

---

## 작업 1. Playboard 월간 채널 순위 (교차 확인용)

```text
playboard.co에 로그인한 상태에서 채널 순위(Channel chart) 메뉴로 가서 아래 6개 순위를 확인해 줘.
기간은 '월간(Monthly)' 또는 가장 긴 기간으로 선택해.

1) 대한민국 · 음악(Music) · 가장 많이 본(Most viewed)
2) 대한민국 · 음악(Music) · 가장 많이 성장한(Most growing / 급상승)
3) 전 세계 · 음악(Music) · 가장 많이 본
4) 전 세계 · 음악(Music) · 가장 많이 성장한
5) 대한민국 · 전체 · 쇼츠 조회수 순위가 있으면 그것
6) 전 세계 · 전체 · 쇼츠 조회수 순위가 있으면 그것

각 순위의 1~30위를 CSV로 정리해 줘.
열: 순위표이름, 순위, 채널명, 채널주소, 기간조회수, 구독자수, 증가율(있으면)
유료 플랜이 필요해서 막히면 볼 수 있는 데까지만 적고 "유료 필요"라고 표시해.
```

## 작업 2. Social Blade 30일 지표 (각 채널)

```text
docs/youtube-benchmark/channels.csv 파일의 channel_id 열에 있는 채널을 하나씩
https://socialblade.com/youtube/channel/{channel_id} 로 열어서 아래 값을 적어 줘.

열: channel_id, 채널명, 최근30일조회수(Views for the last 30 days), 최근30일구독자증가,
    국가, 카테고리(Channel Type), 채널생성일, 소셜블레이드등급(Grade)

한 번에 너무 빨리 열지 말고, 막히면 그 채널은 비워 두고 다음으로 넘어가.
```

## 작업 3. 유튜브 채널 '정보' 창

```text
같은 channels.csv의 각 채널 유튜브 페이지에서 채널 설명 옆 '더보기'(정보) 창을 열어
아래 값을 적어 줘.

열: channel_id, 가입일, 총조회수, 국가, 링크(외부 링크 전부), 이메일 문의 여부
```

## 작업 4. 대표 영상 태그·설명 (선택)

```text
channels.csv의 각 채널에서 최근 30일 안에 올린 영상 중 조회수가 가장 높은 영상 1개를 열어
아래 값을 적어 줘. vidIQ나 TubeBuddy 확장 프로그램이 있으면 태그를 거기서 확인해.

열: channel_id, 영상주소, 제목, 조회수, 업로드일, 길이, 태그(전부), 설명란 첫 5줄,
    고정 댓글 내용, 챕터(타임라인) 유무, 썸네일 특징(글자, 색, 인물 유무)
```

## 작업 5. 쇼츠 채널 보강 (선택)

```text
유튜브 앱이나 웹의 쇼츠 피드를 한국 계정 기준으로 30개 넘겨 보면서,
조회수 100만 이상인 쇼츠의 채널명, 쇼츠 주소, 조회수, 주제, 길이, 사용 음악을 적어 줘.
같은 채널이 여러 번 나오면 횟수도 세 줘.
```
