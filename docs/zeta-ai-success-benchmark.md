## 2. 성공 비결 8가지

### ① 포지셔닝: "생산성 AI"가 아니라 "재미 AI"

- 김종윤 대표: 광고 기반 모델은 이용자가 깊이 몰입해야만 성립하기 때문에 "재미에 집중한다".
- 경쟁 상대를 ChatGPT가 아니라 **웹소설·웹툰·게임**으로 잡았다. 메타 키워드에 '웹소설, 웹툰, 스토리'와 함께 c.ai, talkie 같은 경쟁 서비스 이름을 넣었다.
- 이용자가 주인공이 되는 **인터랙티브 소설**이다. 로맨스, 로판, 학원물, 빙의물처럼 1020이 이미 소비하던 장르를 그대로 옮겨 왔다.

> **벤치마킹 포인트**: AI 기능보다 **목표 고객이 이미 시간을 쓰는 콘텐츠 장르**에서 시작하라. 핵심 지표는 사용자 수보다 체류시간과 재방문이다.

### ② 원가 구조: 자체 소형 모델로 "무료 무제한"을 가능하게 했다

- 자체 언어모델 **Spotwrite-1**을 쓴다. 대화 한 번마다 드는 추론 비용을 줄이려고 직접 만들었다.
- 그래서 "다른 덴 유료, 이 집은 무료"라는 슬로건을 내걸 수 있었다. 앱 설명에서도 "긴 스토리도 무료로 이어 갈 수 있다"를 강조한다.
- 무료 사용량이 늘수록 손해가 나는 대신 광고 수익이 커지는 **역전 구조**를 만들었다.
- 이루다(2020) 시절부터 쌓은 대화형 AI 경험과 핑퐁 팀이 이 기반이 됐다.

> **벤치마킹 포인트**: 대화형 서비스는 **대화 1회당 추론 비용**이 사업성을 좌우한다. 처음엔 외부 API로 시작하더라도, 체류시간이 길어지는 단계에서는 소형·특화 모델이나 라우팅(쉬운 대화는 싼 모델)으로 원가를 내려야 무료 정책을 버틸 수 있다.

### ③ 수익 모델: 광고 + 몰입형 유료 티어

웹 번들 분석으로 확인한 구조:

| 수익원 | 내용 |
| --- | --- |
| 광고 | Google Ad Manager 스크립트가 들어 있다 |
| 유료 재화 | "피스(Piece)": 충전, 자동충전, 사용 내역 |
| 구독 | "PASS": 구독 보너스, 해지 예약 상태 |
| 바우처·코드 | `/usage-vouchers`, `/redeem-code` |
| 결제 채널 | Toss Payments, Toss 브랜드페이, CodaPay(해외), 앱스토어, 플레이스토어 |

- 다수의 가벼운 이용자는 **광고**로, 소수의 헤비 이용자는 **재화와 구독**으로 수익을 낸다(전자신문 보도와 일치).
- 미국 진출 이유도 광고 단가 때문이다. 북미 광고 단가가 더 높아 무료+광고 모델이 더 잘 맞는다고 본다.

> **벤치마킹 포인트**: 무료로 쓰게 하되, **몰입도가 가장 높은 순간**(긴 대화, 이미지 생성, 특별 기능)에 유료 지점을 둔다.

### ④ 콘텐츠 공급: 사용자가 만들고, 크리에이터가 키운다 (UGC 플라이휠)

- 사용자가 자연어로 캐릭터와 플롯을 만든다. AI 창작 도우미(`/plots/assistant`)와 로어북(`/lorebooks`)을 제공한다.
- 누적 캐릭터 수는 60만~250만 개로 보도된다(시점마다 다름). 회사가 직접 만들 수 없는 양이다.
- **크리에이터 대시보드**는 플롯별로 노출 → 클릭 → 플레이 → 성공 전환 퍼널을 보여 준다(`/dashboard/:plotId/*`).
  크리에이터가 데이터를 보고 썸네일, 소개 문구, 첫 장면을 고친다.
- 팔로우, 팔로워, 크리에이터 피드, 투표, 댓글, 고정 글로 **크리에이터 팬덤**을 만든다.
- 디스커버 탭에 "지금 꼭 팔로우해야 할 크리에이터" 섹션을 고정으로 둔다.

```
창작 도구 → 플롯 공개 → 디스커버·랭킹 노출 → 대화(체류시간)
     ↑                                          ↓
크리에이터 대시보드·팔로워 ← 댓글·좋아요·피드 반응 ←┘
```

> **벤치마킹 포인트**: 콘텐츠를 직접 만들지 말고 **만드는 사람이 계속 만들고 싶게** 하라. 그 장치가 창작 도구, 성과 데이터, 팬덤 기능이다.

### ⑤ 몰입 장치: 채팅 + 플러그인 = 게임화된 소설

디스커버 노출 플롯 30개에서 집계한 플러그인 사용 빈도:

| 플러그인 | 사용 플롯 수 | 효과 |
| --- | --- | --- |
| `character-diary` (캐릭터 일기) | 21 | 캐릭터 속마음을 보여 준다 → 감정 몰입 |
| `zetagram` (가상 SNS) | 14 | 세계관을 확장한다 |
| `phone-peek` (폰 훔쳐보기) | 14 | 호기심과 엿보는 재미 |
| `message` (메시지) | 14 | 현실처럼 느껴지는 연락 |
| `dream` (꿈) | 13 | 보너스 이야기 |
| `cartoonify` (만화화, 추정) | 12 | 고른 대화 구간을 만화 이미지로 만든다. 유료이고 캐릭터 이미지가 필요하다 (오류 코드로 추정, 결과물 형식은 미확인) |
| `ending` (엔딩) | 11 | 다 봤다는 성취감과 재도전 동기 |
| `relationship-chart`, `quest`, `dice` 등 | 1~4 | 게임 요소 |

- 여기에 **스냅샷**(장면 이미지 원탭 생성), **음성**(캐릭터 TTS), **배경 자동 생성**이 더해진다.
- 시즌 스킨(`HALLOWEEN_PLUGIN_SKIN_2026`)과 할로윈 네 컷 이벤트로 **시즌마다 다시 찾아오게** 만든다.

> **벤치마킹 포인트**: 대화 하나만으로는 금방 질린다. **대화 바깥의 보조 콘텐츠**(일기, SNS, 이미지, 엔딩)를 모듈로 붙여서, 대화가 쌓일수록 더 많은 것을 얻는 구조로 만들어라.

### ⑥ 진입 마찰 제거

- 처음 방문하면 **로그인 없이 익명 토큰을 자동 발급**한다. 바로 탐색하고 대화할 수 있다.
- 소셜 로그인은 카카오, 애플, 구글, 라인. 국가마다 많이 쓰는 계정을 지원한다.
- IP와 브라우저 언어로 자동으로 언어를 고른다.
- 웹과 앱을 함께 운영하고 딥링크(`zeta://`)와 Airbridge로 둘 사이 이동을 추적한다.

> **벤치마킹 포인트**: 첫 대화까지 걸리는 시간을 최소화하라. 가입은 "대화 내용을 저장하고 싶을 때" 하게 만든다.

### ⑦ 운영 민첩성: 배포 없이 바꾸는 홈 화면

- 디스커버 탭은 서버가 내려주는 섹션 목록(`SmallProfile`, `CreatorRow`, `FeedPreviewList` …)으로 구성된다.
  기획전과 큐레이션을 **앱 심사 없이 즉시** 바꿀 수 있다.
- 기능 플래그(`/v1/feature-flags`), A/B 실험(`/v1/ab-experiments`), 응답마다 붙는 `requestId`로 노출 효과를 측정한다.
- 무한 피드(`/v1/infinite-plots`), 랭킹, 신작, 비슷한 플롯 추천 같은 탐색 경로가 여러 갈래다.

> **벤치마킹 포인트**: 홈 화면을 **서버 주도 UI + 실험 체계**로 처음부터 설계하라. 콘텐츠 플랫폼의 성장 속도는 실험 속도로 정해진다.

### ⑧ 글로벌: 번역판으로 콘텐츠 공급을 늘린다

- 인기 플롯을 **번역판(Language Edition)**으로 유통한다. 디스커버 노출 30개 중 16개가 번역판이었다.
- 댓글과 피드에도 번역 API를 붙여 언어가 달라도 커뮤니티가 섞인다.
- 일본은 **현지화를 크게 하지 않고도** 1위를 했다(회사 설명). 로판, 학원물, 이세계처럼 한일이 공유하는 서브컬처 장르 덕으로 보인다.
- 일본 특정상거래법과 자금결제법 고지 페이지, CodaPay 같은 해외 결제를 갖춰 **현지에서 결제가 되게** 했다.

> **벤치마킹 포인트**: 장르 취향이 비슷한 시장부터 들어가라. 한 시장에서 검증된 콘텐츠를 번역해 다른 시장의 공급으로 재활용하라.

## 4. 적용 로드맵 (비슷한 서비스를 만든다면)

| 단계 | 목표 | 할 일 | 핵심 지표 |
| --- | --- | --- | --- |
| 0. 기반 | 안전·법무 | 연령 인증, 유해 대화 필터, 이용시간·결제 한도, 학습 데이터 동의 | 차단율, 우회 성공률 |
| 1. MVP | 첫 대화까지 30초 | 익명 진입, 장르 3~5개, 운영사가 만든 대표 캐릭터 20~30개 | D1 리텐션, 세션당 대화 턴 수 |
| 2. 몰입 | 체류시간 늘리기 | 스냅샷 이미지, 일기·엔딩 같은 플러그인 2~3개, 대화 저장과 이어하기 | 1인당 일 이용시간, D7 리텐션 |
| 3. 공급 | UGC 열기 | 자연어 캐릭터 제작, AI 창작 도우미, 크리에이터 퍼널 대시보드 | 주간 신규 플롯 수, 크리에이터 리텐션 |
| 4. 커뮤니티 | 팬덤 | 팔로우, 피드, 댓글, 랭킹, 시즌 이벤트 | 팔로우 수, 댓글 수, 이벤트 참여율 |
| 5. 수익 | 원가 < 수익 | 광고 + 재화 + 구독, 모델 라우팅으로 추론 원가 절감 | 대화 1회당 원가, ARPU, 유료 전환율 |
| 6. 확장 | 해외 | 번역판, 현지 결제, 현지 법규 고지 | 국가별 MAU, 번역판 비중 |

### 꼭 기억할 공식

```
성공 = (1020이 이미 즐기는 장르) × (무료로 끝없이 할 수 있는 원가 구조)
     × (사용자가 콘텐츠를 만드는 플라이휠) × (대화 밖의 몰입 장치)
     − (안전·규제 리스크)
```
